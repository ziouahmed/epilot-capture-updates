# e-Pilot Capture Pro — mises à jour Android

Ce dépôt public sert uniquement à **distribuer les versions de l'application
Android e-Pilot Capture Pro**, l'extension mobile d'e-Pilot destinée aux
formateurs.

## Installer ou mettre à jour

- **Vous avez déjà l'application (version 1.3.4 ou plus)** : ouvrez
  **Plus → Mise à jour de l'application**, puis *Vérifier maintenant*.
  L'application télécharge et installe la nouvelle version toute seule.
- **Première installation, ou version antérieure à 1.3.4** : ouvrez l'onglet
  **Releases**, prenez le fichier `.apk` de la dernière version, copiez-le sur
  le téléphone et ouvrez-le. Android demandera l'autorisation d'installer une
  application depuis cette source.

## Ce que contient ce dépôt

Uniquement les fichiers `.apk` publiés dans les **Releases**. Aucun code
source, aucune clé, aucune donnée de formateur ou de stagiaire.

Les mises à jour de la version **Windows** d'e-Pilot sont publiées ailleurs :
elles ne se trouvent pas ici.
